Политика конфиденциальности

Редакция 13 ноября 2026 года

Эта политика описывает обработку информации в личном приложении «УЛЫБАШКА AI». Приложение предназначено для одного владельца и не предлагает публичную регистрацию.

Какие данные обрабатываются

В зависимости от включённых функций: сообщения и команды Telegram; задачи, заметки и списки; данные подключённого Gmail (например, заголовки, отправители, темы и содержимое писем, необходимые для запрошенных операций); события календаря; сведения о выбранных файлах Google Drive; технические сведения, необходимые для выполнения запросов и диагностики ошибок.

Для чего используются данные Google

Данные Gmail используются для выполнения конкретных запросов владельца, в том числе поиска, чтения, краткого пересказа писем и подготовки черновиков. Отправка писем требует подтверждения владельца. Данные Google Calendar используются для просмотра расписания и выполнения явно разрешённых изменений. Данные Google Drive используются для выполнения запрошенных операций с файлами в пределах предоставленного доступа.

Доступ третьих сторон и поставщики услуг

Для работы могут использоваться облачная инфраструктура, защищённое хранилище, Telegram и поставщики AI-моделей/API, которым передаются необходимые для конкретной функции данные. Обработка ограничивается задачами приложения и условиями подключённых сервисов. Доступы разных проектов должны быть изолированы; отдельная коммерческая почта не подключается автоматически к личной Gmail-сессии.

Хранение и защита

Данные авторизации и отдельные рабочие записи могут храниться в серверном хранилище для поддержания подключения и сохранения задач между сеансами. Предусмотрены ограничения доступа владельца, защита учётных данных и подтверждения для значимых операций. Срок хранения отдельных данных зависит от технической функции и действующих настроек; отсутствие публичной регистрации не означает отсутствие серверного хранения.

Контроль и отзыв доступа

Владелец может отказаться от использования функций и отозвать разрешение приложения на странице подключений Google. Для запроса о сохранённых данных или удалении данных приложения используйте контакт разработчика. Отзыв доступа Google не означает автоматического удаления всех ранее созданных заметок и иных записей приложения.

Ограниченное использование данных Google

Данные, полученные через Google API, используются для запрошенных владельцем функций. Они не предназначены для продажи, рекламного таргетинга или составления рекламных профилей. Передача техническим поставщикам ограничена необходимостью выполнить запрос владельца. Использование и передача данных Google должны соответствовать требованиям Google API Services User Data Policy, включая Limited Use.

Изменения

Политика обновляется при существенных изменениях функций, способов обработки информации или подключённых поставщиков. Актуальная редакция размещается на этой странице.
